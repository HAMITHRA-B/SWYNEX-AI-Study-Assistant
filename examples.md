# Example inputs and outputs

The exact response is generated live by the Gemini API, so wording can vary.

## Example 1
**Input:** Explain machine learning with an example.

**Expected output style:** A simple definition of machine learning, followed by an example such as an email spam filter learning from labelled messages.

## Example 2
**Input:** What is a Python list? Give a small code example.

**Expected output style:** A definition of a list, a short Python snippet such as `numbers = [1, 2, 3]`, and an explanation that lists store multiple items in order.

## Example 3
**Input:** Explain photosynthesis step by step.

**Expected output style:** A numbered explanation of how plants use sunlight, water, and carbon dioxide to produce glucose and release oxygen.

**Note:** These are example prompts and expected answer styles, not fixed outputs. AI responses may vary.
